# Karlun Learn — 60-second quick start

## On your Windows laptop

1. Download and extract `karlun-learn.zip`.
2. If Node.js is not installed, install the current LTS version from <https://nodejs.org/>.
3. Open the extracted folder and double-click **`START-WINDOWS.bat`**.
4. Your browser opens at **<http://localhost:4173>**. Keep the terminal window open while using Karlun Learn.

No `npm install`, API key, account or paid service is needed.

## Open it on your phone

**Same-Wi-Fi preview:** keep the laptop server running, connect the phone to the same Wi-Fi, then open the `Phone:` URL printed in the terminal.

**Install as a proper app:** upload the project to a GitHub repository, set **Settings → Pages → Build and deployment → GitHub Actions**, wait for the included workflow to publish it, then open the HTTPS Pages address on your phone and choose **Install app** / **Add to Home screen**.

## Add your latest Karlun master plan

Open **Settings → Import master plan**, paste the full plan, press **Compare master plan**, review the changes and only then press **Apply vocabulary changes**. Keep **Archive words missing from it** unchecked unless the text is your complete current master plan.

## Protect your progress

Open **Settings → Backup & restore → Export backup** regularly. Laptop and phone progress is stored separately until cloud sync is added, so restore the backup on another device to move your progress.

For all features, file locations, editing instructions and the current boundaries, see `README.md` and `DEVELOPER-GUIDE.md`.
